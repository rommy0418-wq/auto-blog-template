Chapter 01

이 블로그가 뭔가요?

한 번만 설정해두면 AI가 매일 혼자서 글을 쓰고 발행하는 완전 자동화 블로그입니다. 네이버 블로그나 티스토리처럼 생긴 웹사이트인데, 글 작성을 사람이 하지 않고 AI가 대신 해줘요.

전체 구조 한눈에 보기

역할담당설명
글 쓰기Gemini AI구글의 AI. 주제를 주면 3,000자 분량의 글을 자동으로 씁니다
사진 찾기Unsplash글과 어울리는 사진을 자동으로 가져와 삽입합니다
글 저장Neon DB클라우드 데이터베이스. 생성된 글을 저장합니다
화면 표시Next.js블로그 웹사이트 프레임워크
인터넷 공개Vercel배포 플랫폼. 인터넷 주소를 만들어줍니다

글이 만들어지는 순서

  • 1
    주제 선택

    scripts/topics.ts 파일에 미리 130개의 주제가 준비되어 있어요. 아직 발행 안 된 첫 번째 주제를 자동으로 고릅니다.

  • 2
    Gemini가 글 작성

    선택된 주제로 약 3,000자 분량의 HTML 글을 생성합니다. 표, 목록, 강조 등 자동으로 구성해요.

  • 3
    Unsplash에서 사진 가져오기

    글 카테고리에 맞는 사진을 썸네일 1장 + 본문 2장 자동 삽입합니다.

  • 4
    DB에 저장 & 즉시 발행

    Neon DB에 저장되고 블로그 메인 화면에 바로 나타납니다.

현재 블로그는 Vercel에 배포되어 https://aitrans-lab.com으로 접속 가능합니다. GitHub Actions로 평일 매일 오전 9시에 글이 자동 생성됩니다.

Chapter 02

블로그 주제 선정 & 변경

블로그 이름, 주제, 카테고리를 바꾸는 방법을 설명합니다. 두 가지 파일만 수정하면 됩니다.

1. 블로그 이름 & 주소 변경

파일 위치: ~/Desktop/auto-blog-template/.env.local

# 블로그 이름 (화면 상단에 표시됨)
NEXT_PUBLIC_SITE_NAME=AI전환연구소  ← 여기를 바꾸세요

# 배포 주소 (현재 설정 완료)
NEXT_PUBLIC_SITE_URL=https://aitrans-lab.com

블로그 이름 예시: "요리 한 입", "강아지 일기", "주식 입문 가이드", "육아 꿀팁 모음"

2. 자동 생성 주제 변경

파일 위치: ~/Desktop/auto-blog-template/scripts/topics.ts

이 파일에 130개의 주제가 저장되어 있어요. 아래 형식으로 내 주제로 바꿀 수 있습니다.

// 현재 구조 (예시)
export const allTopics: Topic[] = [
  {
    index: 1,
    slug: "basic-001",           // URL 주소 (영어로, 띄어쓰기 대신 -)
    title: "블로그 주제 완전 초보 가이드",  // 글 제목
    level: "기초편",              // 기초편 / 중급편 / 고급편
    category: "foundation",       // 카테고리 (아래 참고)
    meta_description: "...",     // 검색엔진에 표시될 설명
    keywords: "블로그, 시작, 가이드", // 검색 키워드
  },
  ...
];

카테고리 목록

카테고리 코드화면에 표시되는 이름사용 예시
foundationAI 입문AI 기초, 트렌드, 입문 가이드
tools도구 실전ChatGPT·Claude 등 AI 도구 활용
marketingAI 마케팅AI 광고·콘텐츠·SEO 전략
transform전환 전략기업 AI 전환 로드맵·컨설팅
business1인기업1인 사업자 AI 수익화 모델
cases사례 분석업종별 AI 도입 실전 사례

카테고리 이름도 직접 바꿀 수 있어요. src/app/page.tsx 파일의 categories 배열에서 label을 수정하면 됩니다.

3. AI 글쓰기 스타일 변경

파일 위치: scripts/generate-post.ts → buildPrompt 함수

return `당신은 "${siteName}" 블로그의 전문 작가입니다.

[작성 규칙]
1. 누구나 이해할 수 있는 쉽고 친근한 말투로 작성  ← 수정 가능
2. 반드시 존댓말만 사용
3. 첫 문장은 강한 후킹으로 시작
4. 3500자 내외                                    ← 글자수 조정 가능
...`

주제를 변경한 후 npm run generate를 실행해야 새 주제로 글이 생성됩니다. 이미 발행된 글은 영향받지 않아요.

Chapter 03

글 자동 생성 사용법

글을 생성하는 방법은 두 가지입니다. 버튼 누르듯 수동으로 실행하거나, 매일 정해진 시간에 자동으로 실행되도록 예약할 수 있어요.

1. 수동으로 글 1개 생성하기

터미널(Terminal 앱)을 열고 아래 명령어를 입력하세요.

cd ~/Desktop/auto-blog-template
npm run generate

실행하면 약 15~30초 안에 글이 생성되고, https://aitrans-lab.com 새로고침 시 바로 나타납니다.

실행할 때마다 다음 주제로 글이 1개씩 생성됩니다. 총 130개 주제가 준비되어 있어요.

2. 매일 자동 생성 (GitHub Actions — 이미 설정 완료)

GitHub Actions가 이미 설정되어 있어 평일(월~금) 오전 9시(KST)에 자동으로 글 1개가 생성됩니다. 컴퓨터가 꺼져 있어도 작동합니다.

  • 1
    자동 실행 확인

    GitHub 리포 → Actions 탭에서 실행 이력을 확인할 수 있어요.

  • 2
    수동으로 즉시 실행하기

    GitHub → Actions → "Daily Blog Post Generation" → "Run workflow" 클릭

  • 3
    설정 파일 위치 
    .github/workflows/daily-post.yml

3. 생성 로그 확인

글이 생성될 때마다 로그 파일에 기록됩니다.

# 로그 파일 위치
~/Desktop/auto-blog-template/scripts/generate.log

# 실시간으로 로그 보기
tail -f ~/Desktop/auto-blog-template/scripts/generate.log

4. 이미 생성된 130개 주제 목록 확인

# 발행된 글 목록 확인
curl https://aitrans-lab.com/api/posts?limit=50

현재 GitHub Actions 자동 발행이 설정되어 있어 컴퓨터가 꺼져 있어도 평일 매일 글이 생성됩니다. GitHub → Actions 탭에서 실행 상태를 확인하세요.

Chapter 04

워드프레스처럼 활용하기

AI 자동 생성 외에도, 워드프레스처럼 글을 직접 작성하거나 수정하고 삭제할 수 있습니다. API를 통해 관리합니다.

워드프레스 vs 이 블로그 비교

📘 워드프레스

  • 관리자 페이지(/wp-admin)가 있음
  • 클릭으로 글 작성/수정
  • 플러그인으로 기능 추가
  • 호스팅 비용 발생
  • 글을 직접 써야 함

🤖 이 블로그

  • 관리자 페이지 없음 → API로 관리
  • 터미널 또는 API로 글 작성/수정
  • 코드로 기능 추가
  • 무료 (Vercel + Neon 무료 플랜)
  • AI가 글을 자동으로 씀

글 직접 작성하기 (API 방식)

터미널에서 아래 명령어를 실행하면 글이 바로 등록됩니다.

curl -X POST https://aitrans-lab.com/api/posts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_KEY" \
  -d '{
    "title": "내가 직접 쓴 첫 번째 글",
    "content": "<p>글 내용을 여기에 HTML로 씁니다.</p>",
    "category": "foundation",
    "status": "published"
  }'

Authorization: Bearer 뒤의 값은 .env.local 파일의 ADMIN_API_KEY와 같아야 합니다. 위 키는 예시이며 실제 키로 바꾸세요.

글 수정하기

# 글 ID가 1인 글의 제목 수정
curl -X PATCH https://aitrans-lab.com/api/posts/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_KEY" \
  -d '{"title": "수정된 제목"}'

글 삭제하기

# 글 ID가 1인 글 삭제
curl -X DELETE https://aitrans-lab.com/api/posts/1 \
  -H "Authorization: Bearer YOUR_ADMIN_KEY"

예약 발행 (특정 날짜에 공개)

curl -X POST https://aitrans-lab.com/api/posts \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_KEY" \
  -d '{
    "title": "예약 발행 글",
    "content": "<p>내용</p>",
    "status": "published",
    "published_at": "2026-06-01T09:00:00Z"
  }'

전체 글 목록 확인

# 최신 글 10개
curl https://aitrans-lab.com/api/posts

# 카테고리별 필터
curl "https://aitrans-lab.com/api/posts?category=foundation&page=1&limit=20"

API 관리가 번거롭다면 무료 앱 Postman 또는 Hoppscotch(브라우저)를 쓰면 클릭 방식으로 API를 쓸 수 있어 훨씬 편합니다.

Chapter 06

자주 묻는 질문 & 트러블슈팅

사용 중 자주 겪는 문제와 해결 방법입니다.

자주 묻는 질문

Q. 블로그 서버를 어떻게 켜고 끄나요?

# 서버 켜기
cd ~/Desktop/auto-blog-template && npm run dev

# 서버 끄기: 터미널에서 Ctrl + C

Q. 생성된 글의 주제가 마음에 안 들어요. 삭제하고 다시 만들 수 있나요?

# 글 ID 확인
curl https://aitrans-lab.com/api/posts

# 해당 ID 삭제 후 재생성
curl -X DELETE https://aitrans-lab.com/api/posts/1 \
  -H "Authorization: Bearer YOUR_ADMIN_KEY"

npm run generate

Q. 글이 너무 길거나 짧아요. 조정할 수 있나요?

scripts/generate-post.ts의 buildPrompt 함수에서 아래 부분을 수정하세요.

5. 3500자 내외  ←  원하는 글자 수로 변경 (예: 1500자, 5000자)

Q. 특정 글에 직접 쓴 내용을 추가하고 싶어요.

curl -X PATCH https://aitrans-lab.com/api/posts/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ADMIN_KEY" \
  -d '{"content": "<p>추가하고 싶은 내용</p>"}'

Q. 블로그에 광고(애드센스)를 달 수 있나요?

네. 글이 20개 이상 쌓이면 구글 애드센스에 신청할 수 있어요. 승인 후 .env.local에 아래를 추가하면 자동으로 광고가 붙습니다.

NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-XXXXXXXXXXXXXXXX

Q. 구글 검색에 노출되려면 어떻게 해야 하나요?

이미 설정 완료되었습니다! Google Search Console과 네이버 Search Advisor 모두 등록되어 있고, 사이트맵도 제출했어요. 보통 2~4주 후부터 검색에 나타나기 시작합니다. 진행 상황은 Search Console의 "실적" 메뉴에서 확인하세요.

오류 해결

증상원인해결
로컬에서 흰 화면서버 미실행npm run dev 실행
글 생성 시 DB 오류DATABASE_URL 오류.env.local의 DATABASE_URL 확인
이미지가 안 나와요Unsplash 키 오류.env.local의 UNSPLASH_ACCESS_KEY 확인
글 생성 API 오류Gemini 키 오류 또는 할당량 초과GEMINI_API_KEY 확인, 하루 무료 한도 초과 시 내일 재시도
Vercel 배포 실패환경변수 누락Vercel 대시보드에서 모든 환경변수 입력 확인

오류가 생겼을 때 가장 빠른 해결 방법: 터미널에 나온 빨간 오류 메시지를 그대로 복사해서 Claude Code(지금 이 AI)에게 붙여넣으면 바로 해결해드릴 수 있어요.
