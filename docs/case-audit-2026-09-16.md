# 사례 카테고리 검수 기록 — 2026-09-16

대상: 공개된 사례 카테고리 19개. 제목·본문의 사례/경력/수치 표현과
외부 출처 링크를 1차 점검했다. 링크 부재나 정규식 일치만으로 허위라고
판정한 것이 아니며, 아래 미완료 항목은 상세 사실 검증이 남아 있다.

세 글의 수정본은 scripts/editorial에 저장한다. 적용 명령은
`node --import tsx scripts/apply-case-review.ts --identity-claims --apply`.
`--apply`를 생략하면 파일 검증만 수행한다. 원문 전체 백업과 트랜잭션을
사용하고 기존 글 주소·발행 상태·댓글·조회수는 유지한다.

cases-017·018은 앞선 작업에서 시험 가이드로 수정했고, cases-019는
허구의 고객 협업을 문서 자동화 설계 예시로 교체했다. 이번 세 글 반영 후
사례 19개 중 6개 본문 정정이었다. 아래 추가 작업 후 15개 정정, 4개
상세 검수 대기다. 이는 전체 사이트
139개 글의 검수 완료를 뜻하지 않는다. 재심사를 아직 요청하지 않는다.

목차 페이지가 원래 기획 제목을 표시하던 문제도 수정한다. 공개된 글은
현재 DB 제목을 표시하고, 관리자 수정·삭제 시 목차 캐시도 갱신한다.
주제 원본 목록이나 미발행 주제는 변경하지 않는다.

## 교육·의료 추가 검수

- cases-004: 가상 의료기관의 성과 표와 환자 기록 기반 홍보 권고 삭제.
  환자정보 없는 공개 행정 안내 시험으로 범위를 제한하고 WHO 자료 추가.
  의료적 판단·차트·실제 예약·자동 발송은 이 설계에서 제외한다.
- cases-006: 콴다의 학습 효율·이탈률 및 가상 코칭 성과의 출처가 확인되지
  않아 삭제. 검색 결과 부재를 서비스 무효의 증거로 해석하지 않는다.
  교사의 정답·풀이·수업 적합성 검수와 학습 효과 평가를 분리하고
  분수 계산의 맞는/틀린 풀이를 직접 확인했다. UNESCO 공식 자료 추가.
- 적용: `node --import tsx scripts/apply-case-review.ts --education-health --apply`.
  새 서비스 사용이나 환자·학생 데이터 수집은 하지 않는다.

  원본 대조, 실패 건수, 검수·재작업 시간, 현금 지출을 구분한 시험으로 수정.

  기반 보고서의 사실·해석·제안, 출처 장부와 미확인 정보 처리로 수정.
