# 사례 카테고리 검수 기록 — 2026-09-16

대상: 공개된 사례 카테고리 19개. 제목·본문의 사례/경력/수치 표현과
외부 출처 링크를 1차 점검했다. 링크 부재나 정규식 일치만으로 허위라고
판정한 것이 아니며, 아래 미완료 항목은 상세 사실 검증이 남아 있다.

| 글 | 확인한 문제 | 조치 |
| --- | --- | --- |
| cases-013 | 운영자 제공 기록 없이 30년 현장 경험 서술, 가상기업 성과를 성공담으로 결론 | 경험담과 성과 삭제, 업무 책임·승인 설계로 대체 |
| cases-014 | 연구소가 실제 인수 자문을 수행했다는 서술과 근거 없는 생산성 예측 | 자문 주장 삭제, 기술 자료 요청 가이드로 대체; 투자 판단과 분리 |
| cases-015 | 실제 사용 도구·개인 경험 공개를 표방하면서 가상 성과 제시 | 사용 경험 주장 삭제, 문서 요약의 구성·권한·실패 시험으로 대체 |

세 글의 수정본은 scripts/editorial에 저장한다. 적용 명령은
`node --import tsx scripts/apply-case-review.ts --identity-claims --apply`.
`--apply`를 생략하면 파일 검증만 수행한다. 원문 전체 백업과 트랜잭션을
사용하고 기존 글 주소·발행 상태·댓글·조회수는 유지한다.

cases-017·018은 앞선 작업에서 시험 가이드로 수정했고, cases-019는
허구의 고객 협업을 문서 자동화 설계 예시로 교체했다. 이번 세 글 반영 후
사례 19개 중 6개 본문 정정, 13개 상세 검수 대기다. 이는 전체 사이트
139개 글의 검수 완료를 뜻하지 않는다. 재심사를 아직 요청하지 않는다.

주제 원본 목록이나 미발행 주제는 변경하지 않는다.
