편집 정정 — 2026년 9월 16일. 이전 글의 중개기업·건설기업 사례와 매칭 성공률·공사기간·안전사고 감소 수치는 실제 측정 자료가 아니었습니다. 해당 성과와 투자 가치·계약·안전 판단의 자동화를 쉽게 권하는 표현을 삭제했습니다. 아래는 업무 자료의 누락과 충돌을 찾는 내부 검토용 설계안입니다.

부동산과 건설 자료에는 같은 대상에 관한 서로 다른 날짜·단위·버전의 설명이 섞일 수 있습니다. AI가 그중 하나를 임의로 정답으로 고르지 않도록, 첫 시험에서는 ‘확정 결론’이 아니라 ‘확인할 항목 목록’을 만들게 하는 범위를 제안합니다. 실제 계약이나 현장 운영에 연결하지 않습니다.

1. 자료의 출처와 버전을 나눕니다

입력 항목검토할 사항
대상 식별자서로 다른 매물·동·호·공구의 자료가 섞이지 않았는가
문서 제목·작성일·버전수정본과 폐기본을 구분할 수 있는가
면적·수량·일정단위와 기준일, 예정과 확정 상태가 표시돼 있는가
작성·확인 담당자정보가 충돌할 때 누구에게 물을 것인가
사용 가능 범위외부 AI에 입력해도 되는 자료인지 승인받았는가

먼저 고객·현장과 연결되지 않는 가상 문서로 시험하세요. 실제 자료를 쓰는 경우에는 비공개 도면, 개인 연락처, 계약 조건 등을 무심코 입력하지 않습니다. 문서가 최신처럼 보인다는 이유만으로 권한이나 내용의 정확성이 확인된 것으로 취급하지 않습니다.

2. 충돌을 해소하지 말고 드러내는 시험

가상 입력: 안내문 A에는 “입주 예정일은 10월, 미확정”, 안내문 B에는 “입주 일정은 담당자 확인 필요”라고 적혀 있다고 가정합니다.

출력 예시판정
10월 입주 확정예정·미확정 조건을 없앴으므로 실패
A는 10월 예정이나 미확정, B는 담당자 확인 필요라고 기재각 자료의 표현을 보존
최신 정보이므로 A가 맞음우선순위 규칙과 확인 근거 없이 결론을 냈으므로 실패
입주 가능 여부를 담당자에게 확인할 것확인 질문으로 분리 가능

같은 방식으로 ‘검토 완료’와 ‘조치 완료’, ‘예정 수량’과 ‘확정 수량’을 구분하는지 시험합니다. 단위가 다르면 숫자만 비교하지 말고 단위 확인 대상으로 남깁니다. 원문 일부가 읽히지 않으면 빈칸을 추정해 채우지 않습니다.

3. 출력 양식과 지시문

출력: 항목 / 문서별 원문 위치 / 일치·충돌·누락·확인 필요 / 담당자에게 물을 질문.
제공된 문서만 비교하라. 계약 효력, 투자 가치, 건물 안전, 공사 승인 여부를 판단하지 말라. 예정·미정·조건부 표현을 보존하고, 원문에 없는 날짜와 사실을 만들지 말라.

이 지시문만으로 오류가 방지되지는 않습니다. 파일 읽기와 검토 초안 저장만 허용하고, 계약 발송·도면 변경·현장 지시·일정 확정 권한은 연결하지 않는 구성을 함께 검토하세요.

4. 검토자가 대조할 실패 유형

  • 다른 대상을 같은 문서로 묶었는가
  • 중요한 예외·부정·미완료 표현을 빠뜨렸는가
  • 자료의 버전 차이를 실제 내용 충돌과 혼동했는가
  • 근거 위치가 없거나 존재하지 않는 문서를 인용했는가
  • 확인 질문 대신 투자·법률·안전 결론을 작성했는가

검토 시간이 줄더라도 잘못 확정한 항목이 늘면 그 사실을 함께 기록합니다. 이 작업에서 얻은 결과는 문서 비교 품질이지 계약 성공률이나 안전사고 감소의 증거가 아닙니다. 실제 법률·거래·설계·시공·안전 판단은 해당 자격과 책임을 가진 전문가의 검토 범위로 남깁니다.

다른 업무와의 구분

이 글은 문서 간 충돌·누락 검토에 한정합니다. 현장 메모를 보고서 초안으로 바꾸는 방법은 건설회사 문서 자동화 시험 가이드에서 별도로 다룹니다. 한 시험의 결과를 다른 업무의 승인 근거로 사용하지 않습니다.
