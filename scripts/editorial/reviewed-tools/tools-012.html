ChatGPT 앱 사용과 API 연동은 구분하세요

API는 프로그램이 요청을 보내고 결과를 받는 연결 방식입니다. 앱에서 대화가 가능하다고 동일한 결제·권한·보관 조건으로 API를 쓸 수 있다고 가정하지 않습니다. 실제 모델·요청 형식·가격은 현재 공식 문서와 계정에서 확인해야 합니다. 이 글은 실행 코드를 제공하거나 연동을 검증했다는 보고가 아니라 설계 점검입니다.

API 키는 공개 웹페이지, 프롬프트, 클라이언트 코드, 공유 문서에 넣지 않습니다. 서버 또는 승인된 비밀정보 저장 기능에서 관리하고 필요한 권한만 사용합니다. 오류 로그에 키와 고객 원문이 그대로 남지 않는지도 확인하세요. 노코드 도구를 사용한다면 그 서비스에도 어떤 자료와 키가 저장되는지 검토해야 합니다.
