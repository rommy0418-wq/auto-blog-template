가상 실패: 어제 자료를 오늘 값으로 표시

자료 수집이 실패했는데 화면이 어제 숫자를 그대로 보여 준다고 가정합니다. 설명용 적절한 동작은 마지막 갱신 시각과 현재 확인 실패를 알리는 것입니다. AI가 이를 보고 ‘오늘 매출이 유지됐다’고 설명하면 실제 최신 자료가 없는 상태를 숨긴 해석입니다.

구현 담당자에게 요청할 시험

  • 작은 가상 표의 합계와 화면 숫자가 일치하는지.
  • 필터와 날짜 범위를 바꾸면 분모가 올바르게 바뀌는지.
  • 취소·환불·중복·미입력이 정의대로 처리되는지.
  • 자료 연결 실패와 권한 부족이 화면에 명확히 보이는지.
  • 권한 없는 사용자가 다른 조직·고객 자료를 볼 수 없는지.

차트 축과 단위, 누적·기간 값의 구분도 확인합니다. 여러 지표의 집계 기간이 다르면 같은 표에 있어도 직접 비교할 수 없다는 점을 표시하세요. AI가 만든 설명은 계산 근거와 관찰 사실, 원인 가설을 분리해야 합니다.

운영 문서

지표 소유자, 원자료 위치, 계산 규칙, 갱신 주기, 장애 연락처와 변경 이력을 남깁니다. 정의가 바뀌면 과거 자료와 비교 가능한지 다시 검토해야 합니다. 단순히 그래프 색을 바꾸는 수정과 지표 정의 변경을 같은 버전으로 취급하지 않습니다.

대시보드에서 보인 상관관계를 원인으로 단정하거나 투자·인사 결정을 자동 실행하지 마세요. 중요한 판단에는 원자료 확인과 업무 담당자의 검토가 필요하며 미확인 자료는 그대로 드러내야 합니다.
