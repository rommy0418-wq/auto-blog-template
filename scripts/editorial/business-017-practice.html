먼저 구분할 것: 초안 작성과 실제 실행

채팅창에서 메일 문장을 만드는 것과 실제 메일을 보내는 것은 다릅니다. 일정 등록·메일 발송은 해당 서비스 연결과 권한 설정이 있어야 하며, 도구와 계정에 따라 지원 범위가 다릅니다. 첫 도입에서는 요약과 초안까지만 맡기고 발송·일정 확정은 사람이 하도록 구성하는 것을 권합니다.

실제 기능을 확인할 공식 문서

  • Google Gmail: Gemini로 이메일 초안 작성 — 계정에서 해당 기능을 사용할 수 있는지 확인한 뒤 초안 작성에 활용하세요.
  • Google Calendar: 예약 일정 알아보기 — 가능 시간을 정하고 예약 페이지로 조율하는 기능입니다. 이 기능 자체를 AI라고 볼 필요는 없으며 일부 기능에는 적격 구독이 필요합니다.

고객 원문·연락처·계약서 전체를 무작정 입력하지 마세요. 업무에 필요한 최소 정보만 사용하고 회사의 정보 처리 기준과 도구의 데이터 사용 설정을 확인하세요. 이 키트는 특정 요금제 구매를 전제로 하지 않습니다.
